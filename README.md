# Prism

本地优先的个人知识管理桌面应用：笔记库、PDF 库、网页资源与事务管理集中在一个窗口里。笔记是存放在任意文件夹中的普通 `.md` 文件，不依赖外部编辑器，数据完全归你所有。

## 快速开始

### 环境要求

- Node.js 20+
- Windows（主要开发与测试平台）

### 安装与运行

```bash
npm install
npm run rebuild        # 为 Electron 重新编译 better-sqlite3
npm run generate-icons # 由 icon.svg 生成 icon.png（仅首次或图标变更时）
npm run electron:dev   # 启动开发环境
```

开发环境固定使用 5173 端口，Vite 会同时启动渲染进程与 Electron 主进程，修改渲染层代码即时热更新。

### 首次配置

1. 打开左侧底部 **设置**。
2. **笔记库**：添加一个或多个 Markdown 文件夹路径，Prism 会递归扫描其中的 `.md` 文件。
3. **PDF 库**：选择 PDF 文件夹，应用会扫描并生成封面索引；文件本身仍在系统资源管理器中维护。
4. 返回 **仓库** 页，从侧栏选择笔记库或 PDF 库开始浏览；也可到 **网页资源** 添加资源。

## 功能概览

### 模块导航

顶部左侧三个图标依次为事务、仓库、网页资源，右侧是设置与窗口按钮。应用默认打开事务-日历；点击图标显示对应模块页，已打开的文档标签会保留；再次点击文档标签即回到文档。

### 文档标签与分屏

- 笔记与 PDF 共用顶部同一条标签栏，可以来自不同笔记库或 PDF 库、同时打开。
- 标签支持拖拽排序、滚轮横向滚动、中键或 X 关闭；右键可关闭其他、关闭全部。
- 右键标签选择「在右侧分屏打开」，即可让笔记 + PDF、笔记 + 笔记或 PDF + PDF 左右并排；点击任一窗格聚焦，工具栏与侧栏跟随聚焦窗格。
- 重启后按设置恢复上次的标签、分屏与当前页面。

### 仓库页

仓库页合并了笔记库与 PDF 库：

- 侧栏分为 **笔记库**、**PDF 库** 与 **收藏集** 三段，可分别折叠，内容过多时内部滚动。
- 笔记模式支持标题 / 正文搜索、收藏集与分组、拖拽归类、批量移入回收站。
- PDF 模式支持网格、封面、收藏集、排序与重新扫描。
- 切换库时保留当前内容并淡入新数据，不会出现空屏。

### 笔记编辑

- 阅读 / 编辑双视图，切换时以视口中线为锚点保持位置，默认视图可在设置中配置。
- 自动保存（延迟可调）、大纲、表格、图片尺寸、代码块与公式渲染。
- 支持 wikilink 跳转、图片附件文件夹、拼写与快捷键等编辑器偏好。

### 事务与网页资源

- **事务**：日历是主视图，顶部左栏是选中日 agenda（跟随选中日期，卡片标题即选中日期）、右栏是收集箱（记录输入框 + 未归项目的未安排任务），下方月网格全宽、按自然周滚动，聚焦周展开、上下周渐隐。任务的起始日期到截止日期之间**每一天**都算当日日程，月网格每天显示 chip；只有超过截止日期才标逾期，逾期任务固定在 agenda 顶部。单日任务可拖拽改期，多日任务在任务详情里改起止。收集箱不再单开一页，直接在右栏记录/处理；项目页左侧是输入与任务列表，右侧栏把标题与进度概览合并、下面是纯文本描述和资料；重命名、编辑介绍、打开文件夹、资料新建/关联和右栏折叠在工具栏，归档/删除走左侧项目右键菜单；完成页按日期分组并可清空。项目是可选容器，支持颜色、描述、拖拽排序、归档与完成日志撤销；全局快捷键弹出独立的快速记录小窗（内容直接进收集箱），不唤起主界面。设置「事务 → 项目仓库」后，项目页可新建/关联计划文档与流程白板；新建文件自动进入 `<仓库>/Projects/<项目>/`，并可打开项目文件夹或定位文件。打开已关联的笔记/白板时，编辑器工具栏可直接跳回对应项目；关联多个项目时用下拉选择。
- **网页资源**：保存网址、标题、备注与彩色标签，按标签筛选、拖拽排序。

### 设置

按「通用 / 仓库 / 编辑器 / 白板 / 事务 / 外观 / 搜索 / 快捷键 / 外部程序」分类，仓库页集中管理笔记库与 PDF 库，事务页指定项目仓库。外观支持深色、浅色、跟随系统，可分别调节正文字号、行高、内容宽度以及 H1–H6 与加粗颜色；快捷键可录制并自动检测冲突。通用页可选择关闭窗口时退出或最小化到托盘，并可设置开机自动启动。

默认快捷键（可在设置中修改）：

| 操作 | 快捷键 |
| --- | --- |
| 聚焦搜索 | `Ctrl+F` |
| 切换阅读 / 编辑 | `Ctrl+E` |
| 全局快速记录 | `Ctrl+Shift+N` |
| 呼出主界面 | `Ctrl+Shift+M` |

## 开发

```bash
npm run electron:dev   # Vite + Electron 开发
npm run lint           # tsc --noEmit
npm run verify         # tsc + 文档契约检查
npm run build          # tsc + vite build
npm run electron:build # 打包安装程序
npm run release:win    # verify + electron:build
```

技术栈：Electron + React 19 + TypeScript + Vite + Tailwind，主进程使用 better-sqlite3（WAL 模式）持久化事务、网页资源与索引，渲染进程通过 `window.prism` IPC 调用。

面向 AI 与开发者的文档从 [docs/index.md](docs/index.md) 开始：架构总览、主进程、渲染层、数据模型、编辑器、白板、改动配方、验证发布。项目约定见 [AGENTS.md](AGENTS.md)。

主要目录：

```text
electron/              主进程与 preload
src/lib/workspace/     文档标签、分屏与工作区持久化
src/components/library/仓库页（笔记库 + PDF 库 + 白板库）
src/components/workspace/文档工作区与分屏窗格
src/components/editor/ Markdown 阅读/编辑与块容器
src/components/canvas/ 白板编辑器
src/shared/            跨进程模型、设置注册表、快捷键
docs/                  AI/开发者文档
scripts/               项目维护脚本 + 文档生成/检查
```

## 项目维护脚本

```bash
node scripts/migrate-attachments.mjs <vault...>           # 预览：图片重命名为日期-时间，引用统一为标准 ![](path)
node scripts/migrate-attachments.mjs <vault...> --apply   # 执行（先备份）
node scripts/prune-attachments.mjs <vault...>             # 预览：列出未被引用的图片
node scripts/prune-attachments.mjs <vault...> --apply     # 移动到 .prism-pruned-<ts>/
node scripts/verify-attachments.mjs <vault...>            # 检查所有图片链接是否可解析
```
