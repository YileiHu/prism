# 项目记忆

> 最后核对：v1.0.0（2026-11-26）。只记稳定结论、决策和坑；不写每日流水。整块功能/重构/发布后更新。

## 1. 当前快照

- 版本 `1.0.0`，Electron 43 + React 19 + TS + Vite + SQLite。
- 类型检查基线：`node node_modules/typescript/bin/tsc --noEmit` 通过（本会话沙箱下 `npm run lint` 的 npm 包装受命名管道限制）。
- 没有自动化测试/CI；UI 一律手动验收。
- 2026-11 完成编辑器统一容器（表格/代码/提示卡/公式/嵌入共享块会话与菜单），设计背景见 [编辑器块重构](../design/editor-block-refactor.md)。
- 2026-11 笔记库侧栏改为顶部下拉选择仓库：抽屉里的仓库列表、拖动排序与仓库图标全部移除，顺序固定为 `vault_paths`（设置 → 仓库 用 ↑/↓ 调整）；私密仓库的锁/解锁按钮放在下拉旁边，收藏集去掉折叠头和凹陷框、改用一条分界线。
- 2026-11 网页资源并入资料库：网页资源成为资料库内唯一的无路径来源（与 PDF 库同级），顶级模块只剩事务/资料库/设置；标签仍作分组，资源行与标签分区同时出现在资料库侧栏和工作区侧栏；旧 `workspace_v1` 的 `module: "resources"` 在 resume 时迁移为「资料库 + 资源」。
- 2026-11 资料库共用层：三类仓库的分组展示与交互收口到 `LibraryGroup` 适配器、`GroupNavRow`、`SectionCard`、`CollectionDialogs`、`useLibraryDnd` / `LibraryDragOverlay`、`LibraryTitle` / `SearchLimitHint` 和 `librarySelection`；资源选择记忆从一开始的标签名演进为收藏集 id。
- 2026-11 收藏集统一为单一归属：笔记 / PDF / 网页资源都只能属于一个收藏集（否则未分组），「加入」全部改为「移动」；网页资源的多标签改为 SQLite 收藏集（`resource_collections` + `resources.collection_id`），旧标签表迁移后删除；批量动作统一为移动到收藏集 / 移出收藏集 / 删除。
- 2026-11 收藏集从颜色改为预设图标：侧栏行与内容区标题都显示收藏集图标（右键「选择图标」设置）；`NoteCollectionData` / `PdfCollectionData` 的 `color` 换成 `icon`，`resource_collections` 加 `icon` 并删除 `color` 列；集合内部分组颜色保留。
- 2026-11 关闭行为/托盘/开机启动：`close_behavior`（退出 / 最小化到托盘）、`auto_launch`、`auto_launch_hidden`；托盘按需创建，`--hidden` 登录启动不建主窗口、PDF 库延后到首次建窗；打包版单实例；新增全局「呼出主界面」快捷键。
- 2026-11 删除日程（GTD）模块，任务并入养成：`growth_tasks` + 能力页「总览」里的「任务」卡片（逾期/今天/未来 7 天/更晚/未安排）、快速记录小窗、完成记录与「任务 ↔ 能力」关联。项目/项目资料/月历网格一并移除；冷启动固定进入养成-能力总览。旧库里的 `gtd_*` 表保留为孤儿表，不再读写。
- 2026-11 「养成」1.0 收口（`growth`，独立架构文档 `docs/architecture/growth.md`）：能力量表（等级 1–6 显示 C/B/A/S/SS/SSS、置信 C0–C5、证据 + 只增快照、读时衰减、技能树 / 清档）、赛季/挑战/作品（过关自动升级、L3+ 每级需已通过挑战、强制归因、赛季海报、作品画廊）、元认知（两段式预测 + 自知度、8 段说明书、他评）、编年史 / 年度一页。任务并入养成，原事务模块删除；schema 收敛为 13 张 `growth_*` 表 + `growth_media`，备份 v3，旧 v1/v2 不再导入。

- 2026-11 侧栏分节收口：抽出 `SidebarSection`（可折叠分节标题）+ `useSidebarSection`（按模块 localStorage 记忆开合，`prism_library_sections`），资料库侧栏两个分节使用；养成「元认知」改为固定分组（分割线 + 自知度/说明书/他评三个带图标 `NavItem`，与主导航对齐，不折叠、不使用凹槽 `sidebar-group`），分区状态仍在 `GrowthView.selfSection`，工具栏只剩当前分区的动作；编年史年份切换同时从内容区 `ChipTabs` 改为工具栏胶囊下拉。工具栏 `tabs` 槽目前没有使用者。

- 2026-11 养成信息架构收口：删除独立首页 `overview`；侧栏顺序改为能力 → 赛季 → 编年史 → 元认知，默认进入能力页「总览」；「总览」左栏任务卡撑满、右栏上方领域分布雷达、下方全部能力列表，单领域页保持领域雷达 + 列表；原首页的「今天做什么 / 最近怎么样」两张卡删除。挑战筛选顺序为「全部 / 进行中」且默认全部，编年史默认当前年份。

- 无已知未完成的大规模重构；下一步以用户需求为准。

## 3. 硬坑

- `better-sqlite3` 是原生模块，升级 Electron/重装依赖后必须 `npm run rebuild`。
- Vite 固定 5173 且 `strictPort`；换端口会让 Electron 白屏。
- 下拉/浮层定位要按**锚点几何**封顶（下方 `top`、上方 `bottom`，`max-height` = 该侧剩余空间），菜单自身高度只用来选方向；用测量高度反推 `max-height` 会在 border-box 下差 1–2px，表现为每次打开都有细滚动条。
- 路径比较必须走 `pathKey`/`normalizePath`；Windows/macOS 大小写不敏感。
- 笔记保存要把真实 mtime 写进 DB，否则 watcher 会重复扫描。
- 冷启动回日历只在 `WorkspaceProvider.hydrate` 里做；不要监听窗口 `focus`/托盘显示去切模块，否则托盘恢复会丢现场；托盘重建窗口必须走 `createWindow(true)`，否则 `?restore-workspace=1` 丢失、现场无法恢复。
- 托盘驻留/`--hidden` 启动时没有主窗口：`window-all-closed` 必须放行，否则关掉快速记录小窗会把应用一起退出。
- `app.setLoginItemSettings` 只在打包版写（开发模式注册的是 electron.exe）；托盘图标依赖 `public/icon-16.png` 被打包。
- 私密库锁定后标签会关闭、索引不可用；不要把它当 bug。
- 白板标签用 `display:none` 隐藏；React Flow 会写内联 `visibility`，祖先 visibility 方案无效。
- MCP 桥接的 `server/package.json` 必须声明 CommonJS：bundle 根 `"type": "module"` 会让 `server.js` 按 ESM 运行并报 `require is not defined`，DSH 侧只显示 `Connection closed`。另外 `cordis.patch.yml` 里是绝对路径，仓库搬家后要改并重装。
- 资料库 `CanvasGroup`（侧栏分组）与画布 `CanvasGroup`（内部容器）是两个类型，不要混用。
- 编辑器块编辑必须走 `BlockSession`/container spec；直接 focus 子编辑器会破坏选区恢复。
- `LibraryRef` 增加 `resources` 后，所有读取 `library.vaultPath` 的分支必须先窄化（`note`/`canvas`）；网页资源不是 `vault_paths` 仓库，不要给它路径、扫描、watcher 或私密逻辑。
- 资料库分组统一走 `LibraryGroup` + `GroupNavRow` / `SectionCard` / `CollectionDialogs`；新增来源不要复制侧栏行、对话框或 `useLibraryDnd` 的状态机。
- `docs/reference/*` 是生成物；改源码后跑 `npm run docs`，不要手改。
- 发布前核对 `release/latest.yml` 与实际安装包文件名（历史上出现过不一致）。

更多见 [排错](../guides/troubleshooting.md)。
